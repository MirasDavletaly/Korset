# Korset — карта Астаны

Демо городского картографического сервиса: поиск адресов и мест, справочник организаций по рубрикам, карточки объектов и маршруты.

**Открыть демо:** https://mirasdavletaly.github.io/Korset/

## Что умеет

- **Поиск с подсказками** — улицы, дома, организации, районы; управление стрелками, Enter, Esc. Запрос вроде «аптека» или «банкомат» сразу открывает рубрику.
- **8 рубрик** — аптеки, кафе и рестораны, продукты, банкоматы и банки, АЗС, медицина, школы и детсады, парковки. Маркеры с кластеризацией, список по расстоянию, фильтр «Открыто сейчас», кнопка «Искать в этой области».
- **Карточка места** — адрес, статус по часам работы («Открыто до 22:00»), телефон, сайт, доступность для колясок, кухня; «Маршрут сюда», «Отсюда», «Поделиться», «Открыть в OSM». Клик по пустому месту карты показывает адрес точки.
- **Маршруты** — авто, пешком, велосипед; альтернативы, время и расстояние, пошаговые подсказки на русском. Точки А и Б перетаскиваются, ставятся правым кликом или долгим нажатием.
- **Карта** — светлая и тёмная тема, 2D/3D с объёмными зданиями, «Моё местоположение».
- **Ссылка хранит состояние** — центр, масштаб, выбранное место, рубрику и маршрут. Ей можно поделиться, обновление страницы ничего не теряет.
- **Телефон** — нижняя шторка с тремя положениями, перетаскивается пальцем.

## Данные и сервисы

Всё построено на открытых данных OpenStreetMap и бесплатных публичных сервисах, без API-ключей:

| Задача | Сервис |
|---|---|
| Карта | MapLibre GL JS + стили OpenFreeMap |
| Подсказки поиска | Photon (komoot) |
| Адрес точки | Nominatim |
| Рубрики | Overpass API (резерв — категории Photon) |
| Маршруты | OSRM, серверы FOSSGIS |
| Часы работы | библиотека opening_hours |

Публичные серверы бывают перегружены, особенно Overpass. Если он не отвечает, рубрика показывает упрощённый список из Photon (до 50 мест, без часов работы). Для продакшена нужны собственные тайлы, геокодер и маршрутизатор.

## Запуск локально

Это один файл `index.html` без сборки. Геолокация работает только по HTTPS или на `localhost`:

```
python -m http.server 8000
```

и откройте http://localhost:8000
