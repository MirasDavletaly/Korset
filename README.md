# Korset — карта Астаны

Городская карта Астаны с собственным движком на чистом JavaScript: 2D и 3D, поиск адресов и организаций, рубрики, карточки мест и маршруты на авто, пешком и на велосипеде.

**Открыть:** https://mirasdavletaly.github.io/Korset/

Карта целиком работает в браузере: ни тайловых серверов, ни геокодеров, ни маршрутизаторов, ни сторонних библиотек. Данные города лежат в `data/`, рисует их WebGL2.

## Что умеет

- **2D и 3D.** Плоская карта и объёмные здания с освещением (высоты из этажности). Поворот и наклон — правой кнопкой мыши или двумя пальцами.
- **Поиск** по улицам, адресам («Кенесары 40»), организациям и районам. Подсказки появляются мгновенно, понимают казахские и русские названия. Запрос вроде «аптека» открывает рубрику.
- **8 рубрик:** аптеки, кафе и рестораны, продукты, банкоматы и банки, АЗС, медицина, школы и детсады, парковки. Все места рубрики на карте с кластерами, список по видимой области обновляется при сдвиге карты, фильтр «Открыто сейчас».
- **Карточка места:** адрес, статус по часам работы («Открыто до 22:00»), телефон, сайт, доступность для колясок, кухня. Клик по зданию — адрес, высота и организации внутри.
- **Маршруты:** до трёх вариантов, время и расстояние, пошаговые подсказки на русском, перетаскиваемые точки А и Б, меню «Отсюда / Сюда» по правому клику или долгому нажатию.
- **Светлая и тёмная тема**, «Моё местоположение», ссылка хранит карту, место, рубрику и маршрут.
- **Телефон:** нижняя шторка с тремя положениями.

## Как устроено

```
index.html            разметка
css/                  токены тем, панель, карта, телефон
js/
  main.js             запуск и связка модулей
  config.js           город, рубрики, словари
  app.js              общее состояние
  core/               DOM, иконки, форматирование, текст, геометрия, матрицы, сетка
  data/store.js       загрузка и индексы данных
  map/                движок карты: камера, WebGL-рендер, триангуляция, подписи, маркеры, жесты
  search/             поисковый индекс и подсказки
  catalog/            рубрики, часы работы
  place/              карточка места, адрес по точке
  route/              граф дорог, A*, подсказки, панель маршрута
  ui/                 панель, шторка, ссылка, меню, уведомления, геолокация
data/                 base.json (рельеф и дороги), buildings.json, places.json
tools/                сборка данных из OpenStreetMap
```

### Обновить данные

```
# 1. Выгрузка Казахстана (~225 МБ)
curl -L -o kazakhstan.osm.pbf https://download.geofabrik.de/asia/kazakhstan-latest.osm.pbf
# 2. Сборка data/ — около 15 секунд, только встроенные модули Node.js 18+
node tools/build-data.mjs kazakhstan.osm.pbf data
```

## Запуск локально

Нужен любой статический веб-сервер (ES-модули не открываются как файл):

```
python -m http.server 8000
```

и откройте http://localhost:8000. Геолокация работает только по HTTPS или на `localhost`.
